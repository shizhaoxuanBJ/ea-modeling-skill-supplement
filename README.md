# Supplementary Material

**From Teaching Rules to Delegating Methods: Scaling Enterprise Architecture Modeling with LLM Agent Skills** (CAiSE 2027 submission, anonymized for double-blind review)

The study was conducted in a live project at a large state-owned enterprise. Raw business documents, the views produced in the project and interview transcripts contain confidential business information and cannot be published. This package provides everything else that is needed to understand, re-use and re-run the method and to recompute the reported statistics.

## About the released skill

`skill/` is a cleaned, generalized release of the skill, prepared after the study for re-use outside the case organization. It implements the five design principles (DP1-DP5) for **business architecture** (views B1-B5): an input contract (DP3), an intermediate representation `biz_data.json` (DP2), a judgment library of negative patterns (DP1), a deterministic validator with a generate-validate-repair loop (DP4), and a governance loop with rulings, write-back and a cross-domain registry (DP5). Its README is `skill/SKILL.md`.

It differs from the configuration used in the study in three respects:

1. **Scope.** The study's skill also generated data, application and technology views; this release covers business architecture only.
2. **Generality.** Case-specific content was removed: the 32-item contract was generalized to a 12-item business-architecture contract, the 48 case-specific negative patterns were replaced by industry-independent patterns plus an optional construction-industry pack, and organization-specific settings are now configuration profiles (`generic-en`, `generic-zh`).
3. **Data.** The examples (`skill/scripts/examples/`) are illustrative domains (resource management in English; hospital outpatient services in Chinese), not data from the case organization.

The numbers in the paper can therefore not be regenerated by running this release on new inputs; they can be recomputed from the aggregated data with `analysis/`.

Language: all documentation, comments and messages are in English. Chinese text remains only where it is data: Chinese word lists used to check Chinese input, Chinese output labels of the `generic-zh` profile, font names, and the Chinese example.

Quick start (Python 3.10+, `pip install python-pptx openpyxl pillow`):

```bash
cd skill/scripts
python check_model.py examples/resource-management-en.json --registry registry.example.json --rulings ../rulings.json --outdir ../outputs
python generate_views.py --data examples/resource-management-en.json --outdir ../outputs
python qa/check_links.py examples/resource-management-en.json
```

## What is not included

Raw enterprise inputs, the views generated or drawn in the project, interview transcripts, the field-level definitions of the IR templates, the prompts of the baseline and ablation configurations, the anchor descriptions of the rating scales, and pair-level or run-level results of Round 3 and the ablation (only aggregated values are provided).
